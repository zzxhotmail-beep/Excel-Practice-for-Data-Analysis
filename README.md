# Bike Sales Analysis | Excel & Google Sheets Portfolio Project

## 📌 Project Overview

This project demonstrates an end-to-end data analysis workflow using Excel and Google Sheets, focused on uncovering customer behavior patterns and delivering business insights through an interactive dashboard.

Using a real-world bike sales dataset, I performed data cleaning, analysis, and visualization to support data-driven decision-making.

## 🎯 Key Business Questions

- How does commute distance influence bike purchase decisions?
- What are the purchase patterns across different age groups?
- Which customer segments show the highest likelihood to purchase bikes?

## 🧠 Key Insights

- Customers with short-to-medium commute distances show higher purchase rates
- Middle-aged customers are the most likely to purchase bikes
- Certain demographic segments demonstrate clear targeting opportunities for marketing

## 🛠️ Skills & Tools

- Excel / Google Sheets
- Pivot Tables (including Calculated Fields)
- Advanced Functions (XLOOKUP, IF, data transformation)
- Data Cleaning & Preprocessing
- Data Visualization (charts & dashboards)
- Interactive Slicers for dynamic filtering

## 🔄 Workflow

- Data Cleaning
  - Removed duplicates and handled missing values
  - Standardized categorical variables for analysis
- Data Analysis
  - Built Pivot Tables to aggregate key metrics
  - Applied calculated fields for deeper insights
- Dashboard Development
  - Designed interactive charts
  - Integrated slicers for multi-dimensional filtering
  - Created a user-friendly dashboard for business users

## 📊 Dashboard Highlights

- Interactive filtering by age group, commute distance, and demographics
- Clear visualization of purchase behavior trends
- Designed for easy interpretation by non-technical stakeholders
